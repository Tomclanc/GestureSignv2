# 多指手势轨迹顺序

绘制时保留实际按下顺序，以便完整捕获各手指。保存和重训时按轨迹的起点 X、起点 Y 稳定排序，并在模板上记录 `OrderByStartPosition: true`。

识别器对这类模板及捕获轨迹使用同一排序规则；排序只创建比较用数组，不改变触点 ID、实际按下顺序或动作插件的数据。两条轨迹交叉时仍按起点对应，因此向内、向外手势保持区别。实时预览、形状检查、转向诊断和纠正样本也采用相同规则。

默认“按位置排序”配置下，旧模板在比较时同样按起点排序，无需重训或修改配置文件。关闭该配置时，未带标记的旧模板保留原来的顺序比较；带标记的新模板仍按起点比较。

首指右键动作继续使用实际按下顺序定位，不受比较数组排序影响。

验证：`GestureSign.MultiTouchDrawingTests` 覆盖双指异向、交叉、三指和五指、旧模板兼容、非默认配置、实际保存和后台加载、多阶段识别及首指右键；`GestureSign.GestureCorrectionTests` 验证纠正模板继承排序规则。
