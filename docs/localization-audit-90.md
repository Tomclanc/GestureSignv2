# 90 种语言和地区变体检查记录

日期：2026-10-13。基于 18.3.7 本轮重打包的源码检查。各渠道实际发布状态以相应 Release、清单提交或商店页面为准。

逐个检查全部 90 个语言目录：每种语言包含 604 条界面文本与 253 条 AI 文本，共 77,130 条资源。此次补齐 21,375 条缺失界面资源，并修正英文残留及部分术语。

## 检查范围与结果

- 扫描全部 WinUI 生产 C# 文件和 XAML，提取本地化调用，检查直接写入控件的中英文标题；本轮提取 1,044 个文本调用。
- 检查目录缺项、空值、重复键、格式占位符、损坏字符、翻译标记残留及非中日语目录中的中文残留。
- 检查整条英文残留及触控板边缘标签中的混合英文短语。品牌、技术缩写和已复核的同拼写词逐语言列在 `tools/localization-unchanged-allowlist.json`；不会将所有英文单词一概视为漏译。
- 修正繁体中文 T/F 提示借用简体中文，以及韩语 T/F 提示绕过语言目录的问题。移除 XAML 中初始化时显示的中文默认标题，交由所选语言填充。
- 全量静态检查：0 个未解决检查项。界面本地化测试通过，覆盖全部 90 种语言的运行时目录查找；AI 资源测试通过，覆盖 22,770 条文本及动态计数、通知和旧消息转换。
- 动作选择和对话框生命周期回归通过。x64 WinUI 编译与发布输出验证通过。
- 已把全量检查加入 CI；后续新增文本未补齐时构建检查会失败。

## 质量边界

本轮采用机器辅助补译、术语修订、代码与资源检查；不是 90 种语言的母语人员逐句校对。检查通过可以确认资源覆盖和格式正确，不能证明所有长句都自然、准确，也未逐个语言打开全部界面做视觉检查。

低资源语言仍需使用者或母语人员复核长句。`nn-NO` 使用挪威语基础翻译并做新挪威语修订；`ca-ES-valencia` 和 `quz-PE` 采用基础语言翻译，地区用语需进一步复核。完整翻译文件已保留，不能把这些质量限制写成已完成母语校对。
