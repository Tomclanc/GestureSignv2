# 动作库使用指南

一个**动作**由若干**步骤**按顺序组成，存放在**动作库**里；轮盘格子和手势都只是去调用这些动作。同一个动作可以同时放在轮盘上、绑定到手势，修改一次处处生效。

## 概念速览

| 名词 | 是什么 | 在哪里改 |
| --- | --- | --- |
| 动作 | 一件要做的事，例如「用 Photoshop 打开选中图片」 | 动作库页面，双击打开编辑窗口 |
| 步骤 | 动作里的一条指令，例如「获取选中的文件」「运行或打开」 | 编辑窗口左侧的步骤面板 |
| 变量 | 步骤之间传递的值，写成 `{files}`、`{folder}` | 编辑窗口的「变量」区；步骤的「保存到变量」 |
| 模板 | 预先做好的动作，选用后只需改几个变量 | 动作库 →「新建动作」→ 从模板 |
| 轮盘格子 | 环形菜单上的一个位置，最多 3 圈 | 轮盘页面，右键格子选动作 |
| 子菜单 | 轮盘格子里再套一层轮盘 | 轮盘页面，右键格子 →「新建子菜单」 |
| 手势调用动作库 | 手势的命令选「动作库动作」 | 手势 → 编辑动作 → 命令 |

轮盘和手势都可以按程序分别设置：给某个程序单独配一套轮盘时，没设置的格子会沿用全局轮盘。

## 上手：三步做出第一个动作

1. **新建**：动作库 →「新建动作」，选一个模板。在「变量」区双击变量改默认值，需要路径时点「浏览」。
2. **测试**：点「测试运行」，3 秒内切到目标窗口（例如先在资源管理器里选好文件），动作会在那里执行。
3. **放上去**：
    - 轮盘：轮盘页面右键一个格子 → 选这个动作。动作会自己显示图标：按它运行的 .exe、.bat、.lnk 快捷方式（取快捷方式指向的程序，没有小箭头）或打开的文件、文件夹取图标；也可以在动作的「外观」里指定图标（图标库、图片、exe 或 .lnk）。
    - 手势：手势的命令选「动作库动作」，再选这个动作。

编辑窗口里：Ctrl+Z / Ctrl+Y 撤销重做，Ctrl+C / Ctrl+V 复制粘贴步骤；步骤可以停用而不删除。

程序路径旁的「示例」按钮列出常用程序、系统设置页和带参数的启动方式，点一下就填好；参数框右上角的 `{ }` 插入变量，「更多写法」里有 `{files:quote}` 这类写法。

## 用例：启动或切换程序

程序没运行就启动，已运行就切到它的窗口（最小化的会还原），已经在最前面时可以收起。模板：**系统 → 启动或切换程序**；步骤：「启动或切换程序」。

| 设置 | 作用 |
| --- | --- |
| 程序路径或名称 | 要启动的东西：完整路径、`notepad.exe` 这样的名字、`.lnk` 快捷方式或 `.bat` |
| 启动参数 | 只在启动时使用 |
| 窗口所属程序 | 启动的和最终开窗口的不是同一个程序时填，可只写 `xxx.exe`，也可写完整路径 |
| 启动时隐藏命令行窗口 | 只对 `.bat` / `.cmd` 起作用，脚本在后台运行 |
| 窗口标题包含 | 一个程序有多种窗口时，只匹配标题里有这段文字的 |
| 已经在最前面时 | 最小化（默认）、切换到它的下一个窗口、不操作 |

**示例一：用 .bat 启动的微信小店助手**。启动用「启动微信小店助手.bat」，窗口属于 `C:\Program Files\Tencent\WeixinStoreAssistant\微信小店助手.exe`。

| 设置 | 填什么 |
| --- | --- |
| 程序路径或名称 | `…\启动微信小店助手.bat` |
| 窗口所属程序 | `微信小店助手.exe` |
| 启动时隐藏命令行窗口 | 脚本不需要显示内容就勾上 |
| 已经在最前面时 | 最小化 |

效果：没运行 → 执行 .bat（工作目录是 .bat 所在文件夹）；已运行 → 切过去；在最前面 → 最小化。

**示例二：VS Code**。路径填 `code`（实际是 code.cmd），窗口所属程序填 `Code.exe`；「示例」菜单里已经配好。Windows 终端同理：`wt.exe` + `WindowsTerminal.exe`。

**示例三：在浏览器窗口间轮换**。路径填 `chrome.exe`，「已经在最前面时」选「切换到它的下一个窗口」。

**示例四：只切到某一类窗口**。VS Code 开了多个项目时，「窗口标题包含」填项目名。

## 用例：对选中的文件和当前文件夹操作

在资源管理器或桌面选中文件后触发，「获取选中的文件」拿到它们的完整路径，「获取当前文件夹」拿到正在看的文件夹。

| 想做的事 | 模板 | 要改的变量 |
| --- | --- | --- |
| 选中图片用 Photoshop 打开 | 文件 → 用指定程序打开选中文件 | `program` = Photoshop.exe 路径 |
| 在当前文件夹开终端 | 文件 → 在当前文件夹打开终端 | `terminal`（默认 `wt.exe`）、`admin` |
| 用 VS Code 打开当前文件夹 | 文件 → 用程序打开当前文件夹 | `program`（默认 `code`） |
| 复制选中文件的路径 | 剪贴板 → 复制文件路径 | 无 |

**示例：选中图片，轮盘一移就用 Photoshop 打开**

1. 用模板「用指定程序打开选中文件」新建动作，双击变量 `program` →「浏览」选 Photoshop.exe。
2. 把动作放到轮盘的一个格子上，图标会自动显示 Photoshop 的图标（也可以在外观里手动选 Photoshop.exe）。
3. 在资源管理器选中一张或多张图片 → 中键呼出轮盘 → 移到这个格子松开。多张图片会一次全部交给 Photoshop。

步骤结构：

```
获取选中的文件        → 保存到 files
如果/否则           条件 files.length > 0
    运行或打开        程序 {program}，参数 {extraArguments} {files:quote}
否则
    提示消息          没有选中文件
```

想逐个文件处理，把「运行或打开」放进「循环每一项」，列表填 `{files}`（当前项变量默认叫 item），参数写 `{item:quote}`。

读取方式：Windows 资源管理器直接读取（Win11 多标签页时只读当前标签）；桌面和其他文件管理器用 Ctrl+C 读取，读完还原剪贴板。

## 用例：带参数启动程序、打开系统设置

「运行或打开」步骤接受程序、文件、网址或系统链接，可加参数、起始位置，也可以以管理员身份运行。模板：**系统 → 打开系统设置或工具** 或 **系统 → 运行程序**。下面这些在「示例」按钮里都有。

| 打开 | 程序 | 参数 |
| --- | --- | --- |
| 显示设置 | `ms-settings:display` | |
| 蓝牙 | `ms-settings:bluetooth` | |
| 声音 | `ms-settings:sound` | |
| 各应用音量 | `ms-settings:apps-volume` | |
| Windows 更新 | `ms-settings:windowsupdate` | |
| 默认应用 | `ms-settings:defaultapps` | |
| 网络连接 | `ncpa.cpl` | |
| 设备管理器 | `devmgmt.msc` | |
| 磁盘管理 | `diskmgmt.msc` | |
| 服务 | `services.msc` | |
| 任务管理器 | `taskmgr` | |
| 注册表编辑器 | `regedit` | |
| 控制面板 | `control` | |
| 程序和功能 | `appwiz.cpl` | |
| 环境变量 | `rundll32.exe` | `sysdm.cpl,EditEnvironmentVariables` |
| 启动文件夹 | `shell:startup` | |
| 锁屏 | `rundll32.exe` | `user32.dll,LockWorkStation` |

| 想做的事 | 程序 | 参数 |
| --- | --- | --- |
| Edge 无痕窗口 | `msedge.exe` | `--inprivate` |
| Chrome 无痕窗口 | `chrome.exe` | `--incognito` |
| 在资源管理器中定位选中的文件 | `explorer.exe` | `/select,{files:quote}` |
| Windows 终端用指定配置 | `wt.exe` | `-p "PowerShell"` |
| 远程桌面连接 | `mstsc.exe` | `/v:主机名或IP` |
| 立即重启 | `shutdown.exe` | `/r /t 0` |

**以管理员身份运行**：勾上后会弹出系统确认；点「否」只会跳过，不报错。以管理员运行时不能同时「等待结束并读取输出」。

**读取命令输出**：勾「等待结束并读取输出」，输出存入变量，最多等 30 秒。例如程序 `cmd.exe`、参数 `/c chcp 65001>nul & ipconfig`，再用「显示文本窗口」显示 `{output}`。`chcp 65001>nul &` 把输出改成 UTF-8，中文才不会乱码。

## 用例：处理选中的文字与 AI

先选中文字再触发；「获取选中的文本」用 Ctrl+C 读取，读完还原剪贴板。没选中文字时会提示，不会调用 AI。

| 分类 | 模板 |
| --- | --- |
| 网络 | 搜索选中文字、输入关键词搜索、翻译选中文字、打开网址、打开选中的网址 |
| 文本 | 简繁互换、大小写切换、去除空行、插入当前时间、常用短语、用 JavaScript 处理选中文字 |
| 剪贴板 | 粘贴为纯文本、复制文件路径 |
| AI | AI 翻译选中文字、AI 润色改写、AI 修正错别字和语法、AI 总结、AI 解释、AI 提问（带上选中文字） |

**AI 设置**：动作库顶部「AI 设置」，选服务商后填 API 密钥。内置 DeepSeek、OpenAI、通义千问、智谱、本机 Ollama 的预设，其他兼容 OpenAI 接口的服务手动填地址和模型。单个「AI 处理」步骤也可以填自己的模型和地址，留空就用这里的设置。

**示例：把选中的中文改成商务邮件语气**。从「AI 润色改写」模板新建，把变量 `style` 改成「礼貌、简洁的商务邮件语气」。想先看结果，把最后的「粘贴文本」换成「显示文本窗口」。

## 变量写法速查

| 写法 | 结果 | 用在哪里 |
| --- | --- | --- |
| `{text}` | 原样 | 大多数场合 |
| `{text:url}` | 网址编码 | 拼到搜索链接后面 |
| `{text:json}` | JSON 字符串转义 | HTTP 请求的 JSON 内容 |
| `{folder:quote}` | 加双引号，`C:\` 这类结尾也处理好 | 程序参数里的路径 |
| `{files:quote}` | 列表里每项加引号，用空格连起来 | 一次把多个文件交给程序 |
| `{{` | 一个 `{` 字符 | 需要写花括号本身时 |

| 步骤 | 默认输出变量 | 类型 |
| --- | --- | --- |
| 获取选中的文本 | `text` | 文字 |
| 获取选中的文件 | `files` | 列表 |
| 获取当前文件夹 | `folder` | 文字，取不到时为空 |
| 获取剪贴板文本 | `clipboard` | 文字 |
| AI 处理 | `result` | 文字 |
| 启动或切换程序 | `status` | launched / activated / minimized / none |
| 运行或打开（等待输出） | `output` | 文字 |

「如果/否则」的条件是 JavaScript 表达式，直接写变量名、不加花括号：`text.trim() != ""`、`files.length > 0`、`status == "launched"`。

## 分享与安全

- **导出**：动作库里右键动作 →「导出到文件…」（`.gsaction`）或「复制分享代码」。动作里调用的其他动作库动作会一起打包。
- **导入**：动作库顶部「导入」→「从文件导入…」或「导入分享代码…」。导入的动作是新副本，不会覆盖已有动作。
- **安全提示**会列出：运行程序或命令（含具体命令）、运行脚本、发送网络请求、把文字发给 AI 服务、使用第三方插件。只导入你信任的来源。导入前可以改动作的变量。
- **不会被带出去的**：AI 的 API 密钥、本机文件路径的图标。API 密钥只存在本机的 GestureSign 配置文件里（明文）。

## 常见问题与限制

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 「启动或切换」每次都重新启动 | 用 .bat、快捷方式或启动器启动，窗口属于另一个 exe | 填「窗口所属程序」 |
| 托盘程序被当成没运行 | 只在托盘、没有可见窗口 | 一般无妨：大多数托盘程序再启动一次会弹出原窗口 |
| 「设置」「计算器」等应用商店应用认不出来 | 它们的窗口不属于自己的进程 | 用「运行或打开」，或 `ms-settings:`、`calculator:` 这类链接 |
| 选中文件没读到 | 焦点不在文件列表，或当前窗口不支持 Ctrl+C 复制文件 | 先点一下文件，再在同一个窗口上触发 |
| 当前文件夹为空 | 打开的是「此电脑」「库」这类虚拟位置 | 模板会提示或直接启动程序 |
| 测试运行无反应 | 后台服务没运行，或 3 秒内没切到目标窗口 | 确认托盘里 GestureSign 在运行 |
| 操作管理员窗口无效 | Windows 不允许普通程序向管理员窗口发按键 | 以管理员身份运行 GestureSign |
| AI 步骤报错 | 密钥、地址或模型名不对，或网络不通 | 检查「AI 设置」；超时是 120 秒 |
