# GestureSign V2 18.3.3

- 修复多指绘制和识别的轨迹对应问题：双指可以各自绘制不同方向，先按左指或右指都能识别。默认按位置识别时兼容旧模板。
- 保留双指点按适配：鼠标先移动到首个按下手指的位置，再发送右键。
- 修复手势库显示数量限制，新增和已保存的手势完整显示。
- 完善界面翻译，整合日语翻译资源。
- Kando 下载自动选择 GitHub 最新正式版，并匹配 x64 / ARM64 架构。
- 新增 Kando 检查更新和一键更新，显示版本、更新说明及进度。更新保留菜单和设置，失败时恢复旧版。自行指定的外部 Kando 提供更新指引。

提供 x64 / ARM64 的 MSI 安装包和便携 ZIP，使用系统共享的 .NET 和 WinUI 运行环境，主程序包剔除运行环境包。便携版解压后运行 GestureSign.WinUI.exe；升级前退出旧版设置窗口和托盘后台。现有配置和手势绑定保留。

Kando 作为可选 DLC 独立下载，不捆绑在 MSI 或便携包中；意图学习组件也独立下载。意图学习组件继续使用兼容的 18.3.2 包。
