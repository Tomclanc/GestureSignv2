# GestureSign V2 · 开发者预览 0.3

基于 18.2.8 的实验性开发者预览，重点测试触控板本地意图学习。此版本标记为 Pre-release，不替代稳定版。

## 下载与开始

- **便携版（Windows x64）**：下载 `GestureSign-DeveloperPreview-0.3-win-x64-Portable.zip`，完整解压后运行 `GestureSign.WinUI.exe`。已包含运行环境，无需安装 .NET SDK。请先从托盘退出旧版本，避免单实例继续使用旧后台。
- **可选学习组件**：在主程序「选项 → 本地意图学习」点击「下载学习组件」，也可下载同一发布中的 `GestureSign-IntentDlc-0.3.0-win-x64.zip` 后点击「导入组件包」。组件不捆绑在便携基础包中。
- ARM64 组件供 ARM64 系统配套构建测试；本次便携主程序为 x64。仅构建验证了 ARM64 组件，没有 ARM64/NPU 实机验证。
- `SHA256SUMS.txt` 提供发布资产的校验值。

## 变化

- 采样、训练、样本预览和纠错均集成在主程序选项页，没有独立学习窗口。
- 一次开启后台学习后，随手势后台恢复采样；不弹窗、不打断原动作。候选手势优先保留，普通轨迹限频，总量有上限。
- 有空确认「滚动 / 有意手势」标签，确认样本充足且电脑空闲至少 2 分钟时自动训练。未确认轨迹、模型猜测和未投诉行为不作为训练答案；同一批标签不重复训练。
- 「主动补充样本」保留为可选的 45 秒录制。默认关闭学习，首次训练仍需每类至少 40 条、4 个会话的真实标签。
- 推理尝试兼容 NPU → GPU → CPU。GPU 支持 NVIDIA/AMD/Intel 的 DirectML 路径，无需单独安装 CUDA；自动模式不强制优先独显。个人模型训练使用 CPU。
- 只有留出验证达标后才能手动开启双指智能关闭保护；自动训练不会自行开启保护。卸载组件保留个人样本与模型。

## 测试与边界

- 本地 68 项学习/组件/后台检查、9 组回归及 74 项 TipTap 检查通过。
- 无法确认厂商的软件/匿名显卡跳过硬件初始化，直接尝试 CPU，避免无物理显卡环境误走 DirectML。
- NVIDIA/DirectML 与 AMD/DirectML 各完成 200 组数值对照，最大绝对误差约 2.98e-7。
- 构建和合成数据测试不能证明真实误触改善；需要真实触控板样本验证。
- 后台学习/观察模式仍会执行原动作，首次训练前原有误触仍可能发生。
- 保护仅针对最终识别后的双指智能关闭，不会修复所有误触，也不能恢复已被捕获逻辑吞掉的滚动。
- 便携版与稳定版共用现有用户配置；试用前建议备份自己的手势配置。样本与模型保存在本机，不上传。

详细说明见仓库 `docs/intent-dlc.md`。
